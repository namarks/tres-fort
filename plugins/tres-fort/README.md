# Très Fort plugin

Draft remote MCP plugin for supported Codex/ChatGPT surfaces. Conversations
run in the user's AI app, using its supported account or subscription. Très
Fort stores training data and executes authorized tools; it does not run a
model, accept model API keys, or bundle inference usage.

The manifest and existing Très Fort icon are ready for local validation. The
MCP URL is the actual configured Worker endpoint. This package has **not** been
submitted, approved, published or assigned a consumer install URL. Its metadata
will match the advertised server only after the matching Worker release.

For public distribution choose **With MCP → Universal → OAuth** in the OpenAI
plugin portal. A local plugin manifest is not a published mobile installation.
Use [the submission worksheet](submission.md) and [review cases](review-cases.md).
No personal marketplace, user configuration, credentials or subscriptions are
modified by preparing this package.
